# ChogCare: экран и LED на трансляции

Прошивка для **NodeMCU 1.0 (ESP-12E Module)** и цветного **ST7789 240×320**. Компьютер передаёт благодарность по USB, только когда существующий платёжный процессор окончательно подтвердил получение пожертвования благотворительностью.

Это не обработчик денег. Прошивка не знает кошельков, ключей, Wi-Fi-пароля или адреса платёжного API. Сайт и трансляция остаются на своей текущей схеме; публиковать плату или USB-порт в интернете не нужно.

## 1. Подключение

Перед перестановкой проводов отключи питание/USB. **LED остаётся на D0, а провод RST экрана перенеси с D0 на D1.** Остальные провода экрана не меняй.

| ST7789 | NodeMCU |
| --- | --- |
| CS | D4 |
| DC | D2 |
| RST | D1 |
| SCLK / SCK | D5 |
| MOSI / SDA | D7 |
| VCC | 3V3 |
| BL | 3V3 |
| GND | GND |

Единственный внешний светодиод:

```text
D0 ──[1 кОм]── анод (+ LED −) катод ── GND
```

**LED и RST экрана нельзя подключать к одному пину.** В этой версии LED использует D0 / GPIO16, а RST экрана — D1 / GPIO5; резистор LED обязателен. Не подавай 5 В на GPIO. Обозначения SDA/SCL на этом TFT относятся к SPI, не к четырёхконтактному I²C-экрану. Назначения GPIO описаны в [документации ESP8266](https://arduino-esp8266.readthedocs.io/en/3.1.2/reference.html).

## 2. Прошивка в Arduino IDE

1. Открой `firmware/chogcare_station/chogcare_station.ino` из этой папки. Все пять `.h`, включая `StationArt.h`, должны остаться рядом с `.ino`.
2. В **Tools → Board** выбери **NodeMCU 1.0 (ESP-12E Module)** из установленного пакета ESP8266. Используй CPU 80 MHz, Flash 4 MB и обычную загрузку скетча, без полного стирания flash.
3. В **Tools → Port** выбери порт именно NodeMCU. На текущем компьютере видны COM1 и COM4; это перечисление портов, не подтверждение модели. Сверь порт в IDE, не выбирай наугад.
4. Через Library Manager установи **Adafruit GFX Library**, **Adafruit ST7735 and ST7789 Library**, **Adafruit BusIO**, **U8g2_for_Adafruit_GFX**. На текущем компьютере они уже установлены. ArduinoJson не требуется.
5. Нажми **Verify**, затем **Upload**. После загрузки закрой **Serial Monitor / Serial Plotter**, иначе USB-мост не откроет порт.

Ориентация сохранена из старого скетча: `tft.init(240, 320)` и `setRotation(0)`. Только если физически экран окажется перевёрнут на 180°, поменяй `ROTATION` на `2` в `StationConfig.h` и прошей снова; провода не меняй. Параметры поддерживаются [библиотекой ST7789](https://adafruit.github.io/Adafruit-ST7735-Library/html/class_adafruit___s_t7789.html).

Проверка компиляции из терминала, **без прошивки**:

```powershell
cd C:\Users\User\Documents\Codex\2026-10-07\ghb
npm run station:compile
```

## 3. Сначала тест без денег

После прошивки открой отдельный PowerShell в папке проекта. Вместо `COM4` ниже подставь подтверждённый порт NodeMCU:

```powershell
cd C:\Users\User\Documents\Codex\2026-10-07\ghb
npm run station:demo -- --port COM4
```

Это **демонстрация**, не настоящий платёж: экран показывает ник `DEMO`, сумму `300 CHOG`, а LED мягко светится 20 секунд. Скрипт завершится после подтверждения показа платой. Он не открывает платёжную базу и не отправляет транзакции. На стриме будет видно `DEMO`, поэтому такой тест нельзя представлять как реальный донат.

Проверка только протокола, вообще **без открытия USB**, тоже доступна:

```powershell
node scripts/station-bridge.mjs --demo --simulate
```

## 4. Настоящие пожертвования

Платёжный процесс оставь работающим и разблокированным в его текущем терминале. После демонстрации запусти USB-мост в отдельном окне:

```powershell
cd C:\Users\User\Documents\Codex\2026-10-07\ghb
npm run station -- --port COM4
```

Окно моста должно оставаться открытым. Ничего перезапускать в платёжном коде и ничего менять на Vercel для этого не требуется.

Дальше автоматически:

1. Процессор окончательно подтверждает доставку денег благотворительности. Сам перевод токенов, статус ожидания и запись в лидерборде ещё не включают LED.
2. Мост берёт выбранную сумму пожертвования. Например, при `300 + 30` для пула экран показывает **300 CHOG**, не 330. Это исходный размер пожертвования в CHOG, не сумма полученной благотворительностью валюты после обмена и комиссий.
3. Используется публичный ник из профиля донора. Если он ещё не сохранён, мост ждёт до 30 секунд; затем показывает `CHOG FRIEND`. Кириллица поддерживается, латинские диакритические знаки упрощаются; имя ограничено 24 символами. NFT-картинки на TFT в этой версии не выводятся.
4. Появляются `Thank you`, ник, сумма и фиолетовая монета CHOG из предоставленной картинки. LED плавно загорается, мягко пульсирует и гаснет через 20 секунд. Следующее пожертвование не перебивает текущий показ, а ждёт очереди.

Финальное подтверждение платежа иногда занимает минуты. Это ожидание не отменяется ради раннего включения лампочки.

**Эта версия реагирует на завершённые CHOG-пожертвования.** Выплату NFT-пула в долларах она не превращает в выдуманное количество CHOG. Поддержку отдельного экрана для NFT-субсидий можно добавить отдельно.

## Перезапуск и безопасность

- При первом рабочем запуске мост запоминает текущий конец журнала: старые донаты не воспроизводятся. Запусти мост **до нового тестового пожертвования**.
- Очередь сохраняется отдельно в `work/station/station.sqlite`. Не удаляй её ради восстановления. Обычный перезапуск продолжает незавершённую очередь; после потери питания посреди показа одна незавершённая благодарность может повториться. Повторных денежных переводов мост не делает.
- SQLite-файлы платежей открываются только для чтения; их схема, состояние и контроль целостности не меняются. Мост не загружает финансовые ключи.
- На плату передаются только очищенный ник, сумма и непрозрачный идентификатор события. Адрес кошелька и данные оплаты не передаются и не появляются на экране.
- Wi-Fi платы выключен. Новый HTTP-сервер, публичный маршрут или входящий сетевой порт не создаётся. Мост проверяет существующий локальный API только на `127.0.0.1:4174`.
- При недоступном/заблокированном платёжном процессе новые команды приостанавливаются. При сбое памяти или дисплея очередь удерживается; `pong` не снимает аппаратную ошибку. После устранения неисправности перезапусти плату и мост.
- Это снижает поверхность атаки, но не является гарантией защиты от компрометации самого компьютера, физического доступа или неисправного железа.

## Отображение и диагностика

Все служебные подписи на экране — на английском. Экран ожидания показывает `ChogCare`, фиолетовую монету CHOG и аккуратную строку `CHOG → CHARITY`. После доната — `Thank you`, ник, ту же монету, сумму и `CHOG`. Изображение занимает 128×128 пикселей в ожидании и 96×96 после доната: оно не перекрывает надписи. Размеры текста умеренные: основные подписи около 17–26 пикселей по высоте, ник — около 25, цифры обычной суммы `300` — около 35. Текст белый/светло-розовый на тёмном фоне. Длинные ники и точные суммы прокручиваются один раз за показ без округления. Написание выбранного донором ника сохраняется, в том числе если сам ник содержит кириллицу.

Подключение моста обозначает маленькая зелёная точка справа сверху; тусклая фиолетовая точка означает отсутствие связи. Служебные надписи `USB`/`WAIT` больше не занимают место на экране.

Частота анимации в настройках — целевые 20 кадров/с. Используется буфер полосы 240×32, а не полный 240×320: это экономит память и избегает очистки экрана между кадрами. Подход соответствует [рекомендациям Adafruit по уменьшению мерцания](https://learn.adafruit.com/adafruit-gfx-graphics-library/minimizing-redraw-flicker). Шрифт с кириллицей — из [U8g2_for_Adafruit_GFX](https://github.com/olikraus/U8g2_for_Adafruit_GFX).

`StationArt.h` содержит готовые RGB565-пиксели этой же картинки из `public/chog-donation-coin.png`. Прозрачность сведена к фону дисплея, пропорции сохранены, убраны только прозрачные поля. Два размера занимают 51 200 байт флеш-памяти и не добавляют буфер в RAM. Интернет и PNG-декодер плате не нужны. Для обычной прошивки ничего генерировать не требуется; файл уже готов. Для замены исходной картинки используется офлайн-скрипт `node scripts/build-station-art.mjs <папка-пакета-sharp>`; `--check` проверяет соответствие пикселей исходнику. На текущем компьютере пакет sharp доступен в зависимости рабочего окружения Codex, добавлять его в зависимости сайта не требуется.

Фактическую плавность, цвета и яркость надо проверить на твоём экране и через камеру. Если появились артефакты на длинных SPI-проводах, снизь `SPI_HZ` в `StationConfig.h` с `20000000` до `16000000` или `8000000`.

Если порт занят — закрой Serial Monitor, старый мост или другую программу, которая использует NodeMCU. Если экран постоянно сбрасывается — убедись, что RST экрана перенесён на D1 и больше не соединён с D0, где находится LED. Если после прошивки точка справа сверху тусклая, запусти USB-мост. После обмена сообщениями она станет зелёной.

Для тестов очереди и протокола:

```powershell
npm run station:test
```

Реальная плата не была прошита или протестирована автоматически. Проверка компиляции и программные тесты не заменяют демонстрацию на подключённом стенде.
